# UI カラートークン（ライトモード基準）

UI Toolkit のすべての色を役割ベースのセマンティックトークンで一元管理する。
ダークモードの直書き色を廃止し、**ライトモードを基準**にトークン化する移行作業のリファレンス。

## 単一管理源

`Assets/UI Toolkit/UnityThemes/UnityDefaultRuntimeTheme.tss` の `:root` ブロック。

- このテーマは `Assets/Settings/UI_PanelSettings.asset` に適用され、**全 UIDocument にカスケード**する。
- 各 USS は色リテラル（`rgb(...)`）を書かず、`var(--lpw-...)` で参照する。
- 色を変えるときは原則このブロックだけを編集すれば全画面に反映される。
- 将来ダークモードを足す場合は、ルート要素に `.theme-dark` 等のクラスを付けて同名トークンを上書きする方式を想定（トークン名は据え置き）。

## 移行状況

**全 USS ファイルのトークン化が完了**（2026-06-16）。全画面のチュロム（背景・パネル・テキスト・ボタン・ボーダー・ステータス色）を `var(--lpw-...)` に統一済み。USS エラー/警告 0 件で Unity が解決を確認済み。

## トークン化しない例外（意図的に生の色を残す）

以下は「アプリ UI のテーマ」ではないため、トークン化せずリテラルを維持する。grep（下記 C）でヒットするのはこれらのみが正しい。

1. **ソーシャルサインインボタン**（`TitleScreen`）— Google=白地/Apple=黒地はブランド指定色。
2. **3D ワールド上のフローティング HUD** — 任意の 3D 背景の上で視認性を保つため暗い半透明を維持:
   - `MenuOverlay`（☰ ボタン）, `WorldHUD`（HUD アイコン/アクションボタン）, `PhotoModeHUD`（撮影モード全体）
   - ※ `WorldEditor` のビューポート HUD（コスト表示・地形の上方非表示トグル・高さバー）は他メニューに合わせ**半透明白ベースに変更済み**（暗 HUD 例外から除外）。
3. **ペイントツールの機能面**（`AvatarEditScreen`）— ワークスペース背景（中間グレー=色判断用）・キャンバス本体（白=作品）・現在のペイント色スウォッチ・カラーホイール下地・3Dプレビュー上の戻るボタン。
4. **完全透明** `rgba(0,0,0,0)` — 色ではなく透明指定（hover 前の透明背景・透明ボーダー等）。

## ワールド編集画面（WorldEditor）専用トークン

3D ビューが透けるすりガラス風メニューを実現するため、編集画面のメニュー/バー背景だけ半透明トークンを使う（`--lpw-surface` を半透明にすると全画面に波及するため分離）:

| トークン | 用途 | 値 |
|---|---|---|
| `--lpw-editor-panel` | タブコンテンツ等の主要メニュー・ルール編集/ピッカーのオーバーレイ | `rgba(246,248,251,0.86)` |
| `--lpw-editor-bar` | ヘッダー・タブバー・ツールバー・選択バー・上部ビューポート HUD | `rgba(255,255,255,0.90)` |

透け具合は上記の alpha だけで調整可（不透明に戻すなら 1.0）。

### 白シルエットアイコンのティント

UI アイコン（`Assets/Textures/UI/Icons` の白シルエット PNG・背景画像表示）は明色背景だと白く飛んで見えない。WorldEditor の各アイコンクラス（`.icon-*` / `.terrain-icon` / `.gimmick-icon-btn`）に `-unity-background-image-tint-color: var(--lpw-icon)`（暗色 `rgb(70,76,92)`）を掛けて可視化している。アクセント背景のアクティブ状態（地形ツール active・テストプレイ）はアイコンを `--lpw-text-on-accent`（白）に上書き。新規アイコン追加時も同様にティントすること。[[ui-icon-convention]] 参照。

## 人間による確認手順

### A. パレット承認（残り展開の前に）
1. Unity Editor で `Assets/UI Toolkit/UnityThemes/UnityDefaultRuntimeTheme.tss` を **UI Builder** で開く、または `Assets/UI/HomeScreen.uxml` を UI Builder で開く。
2. UI Builder のキャンバスで背景が**白〜薄グレー（ライト）**、テキストが**濃色**、ナビのアクティブタブが**青**になっていることを確認。
3. `Screens/TitleScreen.uxml` を UI Builder で開き、モーダル（白カード＋暗幕）・プライマリボタン（青地＋白文字）・セカンダリボタン（白地＋枠）・エラーテキスト（赤）の見え方を確認。
4. 色味（青の鮮やかさ、背景の白さ、テキストのコントラスト等）に要望があれば TSS の値を伝える → 全画面に一括反映。

### B. 実機/実行時確認（任意・展開後）
1. `Tools/LowPolyWorld/...` の各プレビュー生成メニュー、または Play モードで対象画面を表示。
2. 画面ごとに背景・テキスト・ボタン・入力欄・ステータス色（成功緑/警告橙/エラー赤）が破綻なくライト表示されることを確認。

### C. トークン未参照の取りこぼし検出（展開後の機械チェック）
リポジトリルートで以下を実行し、ヒットが**ブランド色の例外のみ**になっていることを確認する:

```bash
grep -rnE "rgba?\(" LowPolyWorldUnity/Assets/UI --include=*.uss
```
